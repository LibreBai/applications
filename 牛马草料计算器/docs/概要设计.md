# 牛马草料计算器 · 概要设计

| 项目 | 内容 |
|---|---|
| 适用版本 | v0.7.1 |
| 文档范围 | 核心计算模型（网页版/桌面版两版共用）与桌面版技术选型；实现细节见《详细设计》 |

## 1. 计算模型（核心）

### 1.1 口径与常量
- **月计薪天数 21.75**：按人社部口径 (365 天 − 104 天休息日) ÷ 12 = 21.75 天/月（法定节假日带薪，已含在此口径；周末不计薪）。
- **每日计薪工时**：默认 8 小时。
- **午休**：默认 12:00–13:00（1 小时），不计薪、金额冻结。
- 月收入口径由用户自行把握（建议填"税后到手"），工具只做线性换算，不涉及社保税收。

### 1.2 派生量
| 量 | 公式 | 例：月收入 10,000 元 |
|---|---|---|
| 日均收入 D | M ÷ 21.75 | ¥459.77 |
| 时薪 | D ÷ 8 | ¥57.47 |
| 每分钟 | D ÷ 480 | ¥0.9579 |
| 每秒 R | D ÷ 28,800 | ¥0.015964 |

### 1.3 一日计薪时间线（两档）
**08:30 档**
| 时段 | 时间 | 计薪 |
|---|---|---|
| 上午 | 08:30 – 12:00 | ✅ 3.5 h |
| 午休 | 12:00 – 13:00 | ❌ 冻结 |
| 下午 | 13:00 – 17:30 | ✅ 4.5 h |
| 合计 | 在岗 9 h | 计薪 8 h，17:30 封顶 |

**09:00 档**
| 时段 | 时间 | 计薪 |
|---|---|---|
| 上午 | 09:00 – 12:00 | ✅ 3 h |
| 午休 | 12:00 – 13:00 | ❌ 冻结 |
| 下午 | 13:00 – 18:00 | ✅ 5 h |
| 合计 | 在岗 9 h | 计薪 8 h，18:00 封顶 |

### 1.4 今日累计（核心函数，时间驱动）
设 t 为当前时刻（换算成分钟），`paid(t)` 为今日已计薪分钟数：

```text
paid(t) = 0                       t ≤ 上班
        = t − 上班                上班 < t < 12:00
        = 上午时长                12:00 ≤ t < 13:00    （午休冻结）
        = 上午时长 + t − 13:00    13:00 ≤ t < 下班
        = 480（全天计薪分钟）     t ≥ 下班             （封顶）
```

今日累计 = paid(t) × 每秒收入 R。

**实现原则：任何时刻的数值都由当前钟点直接推导，不做 tick 累加。**
因此休眠/唤醒、页面长时间挂机、甚至修改系统时间，重算结果都天然正确，不会"错账"。

### 1.5 本月累计
```text
本月累计 = (本月 1 日至今日（不含）的工作日数 × D) + 今日实时
```
- 工作日暂指周一至周五（v1 无节假日表）。
- **21.75 均摊的固有特性**：工作日较多的月份（如 23 个），月末累计会略超月收入；2 月则可能不满。这是"按 21.75 平均"定义使然（与工资口径一致）。v1.2 计划提供"按本月实际工作日归一化"开关（使月末必等于月收入）。

### 1.6 状态机
```text
（周六/周日）→ 🎉 周末休息中：今日恒为 0，本月累计照常推进
（工作日）
😴 尚未上班 ──到点──▶ 💻 上午搬砖 ──12:00──▶ 🍜 午休（冻结）──13:00──▶ 💻 下午搬砖 ──下班──▶ ✅ 今日已收工（封顶 = D）
```
摸鱼是**显示层的叠加态**：计薪时段内的任意搬砖状态，按下摸鱼键后状态徽章覆盖为「🐟 摸鱼中（带薪）」，倒计时不变；它不改变时间线本身，只改变钱的归属统计。

### 1.7 摸鱼额度（暂停/继续键）
- 语义：**暂停的是"搬砖"，不是薪水**。按下「🐟 开始摸鱼」表示进入带薪摸鱼状态，工资照涨；摸鱼期间涨的钱单独记入"今日摸鱼额度"。按下「💼 继续搬砖」结算本段。
- 公式：
```text
摸鱼额度 = Σ (每次摸鱼区间 ∩ 当日计薪时段的交集分钟数) × 每分钟收入
```
- 规则：
  1. 只有计薪时段内的摸鱼才计入；午休、下班后、周末摸鱼不白嫖（不计额）。
  2. 摸鱼区间跨过午休：自动只累计计薪部分（由 paid(t) 差值天然保证）。
  3. 多次暂停/继续可累加；本日有效，**跨天自动清零**（含未结算的暂停状态）。
  4. 摸鱼期间休眠/挂机：按真实时钟与计薪时段的交集计（与今日累计同口径）。
  5. **摸鱼额度 ⊆ 今日累计**：它是今日收入的拆分标签，不是额外收入。
- 持久化：当日摸鱼状态与已累计摸鱼分钟本地保存，刷新页面不丢。

### 1.8 边界规则
| 场景 | 行为 |
|---|---|
| 周末打开 | 今日 ¥0、进度 0%，本月累计照常 |
| 月初第 1 个工作日上班前 | 双 0 起步 |
| 跨月 | 自然按"本月 1 日起算"，无需特殊处理 |
| 下班后/深夜挂机 | 今日封顶 D，不再增长 |
| 休眠后唤醒 | 由时钟直接重算，数值即正确 |
| 月收入清空/非法 | 沿用上次有效值 |
| 摸鱼中跨过午休/下班 | 只累计计薪时段交集，越界自动截止 |
| 摸鱼状态过夜 | 跨天清零，重新开始 |

## 2. 桌面版技术选型

**实际采用：方案 D 变体 —— C# WinForms + 系统自带 .NET Framework 4.8 + csc.exe，零安装零依赖。**
选型原因：本机无 Python / Node / Rust / .NET SDK；而 csc.exe 与 .NET Framework 4.8 为 Windows 自带，直接原生编译，产物仅 64 KB（远优于 ≤20 MB 指标），界面用原生控件复刻 Web Demo 的暗色风格与全部计算逻辑。

| 方案 | 技术栈 | 体积 | 复用 Demo | 说明 |
|---|---|---|---|---|
| A. Tauri 2 | Rust + 系统 WebView2 | 3–6 MB | 界面/算法原样复用 | 需 Rust 工具链（本机未安装） |
| B. pywebview + PyInstaller | Python | 12–20 MB | 原样复用 | 需安装 Python（本机未安装） |
| C. Electron | Node + Chromium | 120 MB+ | 原样复用 | 体积过大，不推荐 |
| **D. C# WinForms 原生（✅ 已采用）** | .NET Framework 4.8（系统自带） | **64 KB** | 逻辑等价移植 | 零依赖、双击即用，`src/desktop/build.bat` 编译，根目录 `release.ps1` 一键发布 |

补充说明：网页版本身即跨平台形态（任何现代浏览器可用）；WinForms 为 Windows 专属技术，桌面版不在 Linux/macOS 提供，跨平台需求由网页版覆盖。
