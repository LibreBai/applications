## 1. 网页版详细设计（`src/web/index.html`）

- 文件：单文件、零依赖，双击用浏览器打开（Edge/Chrome 均可，手机亦可）。**源码即交付物**：由根目录 `release.ps1` 拷贝为 `dist/牛马草料计算器网页版.html`。
- 存储：`localStorage`（设置键 `niaoma_income_v1`，摸鱼键 `niaoma_fish_v1` 按天记）。
- 刷新：`requestAnimationFrame` 逐帧按当前时间重算，数字自然跳动。

### 1.2 使用方法
1. 双击打开 `dist/牛马草料计算器网页版.html` → 填月收入 → 点 08:30 或 09:00。
2. 主屏数字实时跳动；浏览器标签页标题也同步显示今日/本月累计。
3. 开始摸鱼（刷手机、带薪拉屎、发呆）时点「🐟 开始摸鱼」，回来点「💼 继续搬砖」，摸鱼额度自动入账。
4. 刷新或重开页面，设置与当日摸鱼进度自动恢复。

### 1.4 v0.7.1 修订（2026-10-19，浏览器实测回归）
- 修复：极端配置（每日工时 < 上班到午休的时长）下，今日累计可超过日均收入的封顶缺失——`schedule()` 上午计薪分钟与 `paidMin()` 现以全天工时封顶。默认配置行为不变；实测工时=1 时今日累计恰好封顶日均 ¥459.7701。
- 实测通过：派生值（日均/时薪/每分钟/每秒）与设计口径一致；摸鱼暂停→结算→跨页面销毁恢复（时间驱动无误差）；08:30/09:00 档切换；设置与摸鱼进度 localStorage 持久化；标签页标题同步；布局无横向溢出。
- 已知边界（非缺陷）：页面不可见时浏览器暂停 requestAnimationFrame，数字静止；切回可见时按当前时间立即重算，数值天然正确。

## 2. 桌面版详细设计（`src/desktop/`）

### 2.1 实现要点
- 原生 C# WinForms 单文件实现（`Program.cs`），零第三方依赖，编译目标 .NET Framework 4.8（选型见《概要设计》第 2 章）。
- v0.7 布局引擎：全界面按"比例坐标"呈现——每个控件的位置/尺寸都以父容器尺寸的百分比记录，窗口缩放/最大化/DPI 变化时按同一比例系整体重排，代码中不写死任何绝对布局坐标；拉伸窗口时锁定设计纵横比（480:788），另一维自动联动；文字标签 AutoSize 永不裁切。
- 计算模型与网页版完全等价（见《概要设计》第 1 章）。

### 2.2 桌面版 v0.4 已含增强
- ✅ 窗口置顶开关（标题栏"置顶"勾选）
- ✅ 最小化到系统托盘（托盘图标：双击唤起 / 右键打开·退出）
- ✅ 窗口/任务栏标题实时显示"今日¥xx · 本月¥xx"
- ✅ 设置与当日摸鱼进度持久化（%APPDATA%\NiuMaIncome\state.ini）
- ✅ 本地时间实时显示（标题区，随秒刷新，对应 FR-11）
- ✅ 启动界面自检（DPI 检测、layout_audit.txt 日志、托盘气泡提示，对应 FR-12）
- ✅ 窗口可自由拉伸 / 最大化，内容整体等比缩放（对应 FR-13）
- ⏳ 开机自启、到账提示音、全局摸鱼快捷键（v1.x）、全局快捷键一键摸鱼打卡

### 2.3 构建与发布
1. 编译：运行 `src/desktop/build.bat`——零依赖（仅用系统自带 csc.exe），自动补生成图标，输出中间产物 `build\NiuMaIncome.exe`（可随时删除）。脚本保持纯 ASCII（cmd 按 ANSI 代码页解析 .bat），故中文改名这步由发布脚本完成。
2. 一键发布：根目录 `release.ps1` = 调用 build.bat 编译 + 把产物改名为 `dist/牛马草料计算器.exe` + 同步网页版到 `dist/牛马草料计算器网页版.html`。`dist/` 里只放交付用户的文件。
3. 图标：`make_icon.ps1` 生成 `icon.ico`（build.bat 检测缺失时自动调用）。
4. 运行时数据：`%APPDATA%\NiuMaIncome\state.ini`（设置与摸鱼进度）、`layout_audit.txt`（每次启动的界面自检日志），首次运行自动生成。
