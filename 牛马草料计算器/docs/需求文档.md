## 1. 项目概述

### 1.1 一句话定位
把月薪换算成"每秒都在到账"的实时数字，让打工人随时看到今天、这个月已经挣了多少钱——顺便算清今天带薪摸鱼白赚了多少。

### 1.2 设计目标
1. **实时正反馈**：今日收入按秒跳动，精确到 0.0001 元，看得见"钱在涨"。
2. **零门槛**：只需输入月总收入、选择上班时间（8:30 / 9:00），其余全自动。
3. **带薪摸鱼可视化**：一键暂停/继续，自动统计本日摸鱼额度。
4. **纯本地**：无网络、无依赖，数据只存在本机。

### 1.3 产品形态
- ✅ 阶段一：单文件网页版（源码 `src/web/index.html` → 交付 `dist/牛马草料计算器网页版.html`），浏览器打开即用。原型存档见 `docs/原型/`（冻结快照，不随版本维护）。
- ✅ 阶段二：Windows 桌面程序 `牛马草料计算器.exe`（64 KB 单文件绿色版，原生 WinForms 实现，技术选型见《概要设计》第 2 章，实现细节见《详细设计》第 2 章）。

## 2. 需求

### 2.1 功能需求
| 编号 | 需求 | 说明 |
|---|---|---|
| FR-1 | 月总收入输入 | 元/月，数字校验（必须 > 0），本地记忆 |
| FR-2 | 21.75 天均摊 | 日均收入 = 月收入 ÷ 21.75 |
| FR-3 | 上班时间两档 | 08:30 / 09:00 切换；对应下班 17:30 / 18:00 |
| FR-4 | 午休不计薪 | 默认 12:00–13:00 共 1 小时，时段可调 |
| FR-5 | 今日累计（实时） | 按秒刷新，4 位小数；午休冻结、下班封顶 |
| FR-6 | 本月累计（实时） | 本月已过工作日 × 日均 + 今日实时 |
| FR-7 | 进度与状态 | 今日/本月进度条、状态（上班中/午休/已下班/周末）、倒计时 |
| FR-8 | 设置持久化 | 月收入、上班档位、工时与午休时段本地保存 |
| FR-9 | 摸鱼暂停/继续键 | 见《概要设计》1.7：标记摸鱼时段，统计**本日摸鱼额度**（时长、金额、占今日比例），跨天清零 |
| FR-10 | 比例显示 | 三处比例必须以"进度条 + 百分比数值"双形式同时呈现（百分比保留 1 位小数）：① 今日计薪进度（已计薪分钟 ÷ 每日工时）② 本月进度（本月累计 ÷ 月收入，封顶 100%）③ 摸鱼占今日收入比例（摸鱼额度 ÷ 今日累计） |
| FR-11 | 本地时间显示 | 界面顶部显示本地当前时间（日期 + 星期 + 时:分:秒），随秒刷新，供用户核对计算口径 |
| FR-12 | 界面自检 | 每次启动按当前 DPI 实测全部文字控件：溢出即记录并托盘气泡提示；按钮文字过窄自动加宽；日志写入 %APPDATA%\NiuMaIncome\layout_audit.txt（桌面版） |
| FR-13 | 窗口等比缩放 | 窗口可拉伸 / 最大化（最小约 0.7 倍），**拉伸时锁定纵横比**：拖任意边或角，另一维自动等比联动（横纵永远同步缩放，不会"拉宽不变高"）；最大化时内容整体等比缩放并在窗口内居中、四周对称留白；启动时兜底确保窗口装得下全部内容（桌面版） |

### 2.2 非功能需求
- NFR-1 **零依赖直接运行**：单文件 exe，免安装、不联网。仅允许依赖 Windows 自带组件——.NET Framework 4.8（Win10 1903+ / Win11 内置）；实测引用仅 mscorlib、System.Windows.Forms、System.Drawing 三个系统程序集。拷贝到任何 Win10/11 机器双击即用，无需安装任何运行时（老系统 Win7/8.1 需一次性安装 .NET Framework 4.8，属已知边界）。启动自检记录本机 .NET 精确版本（layout_audit.txt，低于 4.8 标记"更旧(需升级)"），用于跨设备一致性排查。注：.NET Framework 是系统组件、微软不允许随应用分发；如需完全自带运行时的"绝对一致"版本，走 .NET self-contained 单文件路线（约 100 MB，备选方案）。
- NFR-2 时间驱动计算（见《概要设计》1.4）：休眠唤醒、长时间挂机后数值依然准确。
- NFR-3 exe 版：体积 ≤ 20 MB（实测 64 KB），内存 ≤ 100 MB（实测约 36 MB），双击即用。
- NFR-4 全中文界面，暗色主题。
- NFR-5 **界面自适应（防挤压）**：任意系统缩放比例与分辨率下，文字不得裁切、挤压。实现约束（v0.7 起）：**全界面按比例坐标驱动**——每个控件的位置/尺寸以父容器尺寸的百分比记录，窗口尺寸/DPI 变化时按同一比例系整体重排，代码中不存在写死的绝对布局坐标；文字标签 AutoSize（框随文字走）；居中文本按 GDI 实测宽度动态居中；换行文本按实测高度撑开；字号跟随用户缩放、不随 DPI 双重放大。窗口锁定纵横比拉伸（FR-13）作为交互兜底，启动自检（FR-12）作为质量兜底。

### 2.3 明确不做（v1 边界）
- 不做记账/工资条管理，不对接任何工资系统，不联网。
- v1 不内置法定节假日与调休表（暂按周一至周五计薪），列入 v1.1（见本文档第 4 章「迭代路线」）。
